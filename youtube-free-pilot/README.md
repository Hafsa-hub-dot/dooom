# تجربة يوتيوب المجانية — المرحلة الأولى
هذه التجربة منفصلة تمامًا عن موقع dooom ولا تعدّل ملفات المشروع الأصلي.

- تصميم الفيديو مطابق لمبدأ النسخة التجريبية التي نالت إعجاب صاحبة القناة (ألوان لؤلؤية، حركة ناعمة، نص عربي، توقيع Bent. Tayeb).
- Workflow يعمل فقط عند تحديث فرع pilot/free-youtube-shorts-20261029؛ **لا توجد جدولة** أو نشر أو اتصال بقناة YouTube.
- الاستوديو يولّد مقطع MP4 ويضعه في GitHub Actions Artifacts للتحقق قبل تفعيل OAuth.
- المحتوى العلمي يحتوي 7 موضوعات، كل موضوع لتاريخ واحد بدءًا من 2026-10-29. ينتهي البنك بأمان بعد 7 أيام ولا يكرر المادة تلقائيًا.
- لا تُخزني أي كلمات مرور أو رموز وصول داخل المستودع.
- المرحلة التالية: بعد نجاح GitHub Actions، يلزم إعداد OAuth الخاص بمالك قناة YouTube لاختبار رفع خاص فقط.

طريقة المتابعة: افتحي Actions، ثم Arabic Shorts Pilot، وابحثي عن تشغيل الفرع وملف artifact باسم arabic-shorts-pilot-mp4.
